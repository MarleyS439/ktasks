KTasks — Resumo Inicial
Ecossistema Completo

Tudo do seu fluxo diário em uma interface Kirigami limpa

Projetado para parecer parte nativa do Plasma 6, respeitando tema, esquema de cores Breeze, fontes e ícones do seu desktop.

Painel de Resumo & Clima

Saudação personalizada, dia da semana, KPIs clicáveis, previsão compacta Open-Meteo para 10 dias (com atualização horária), rotina do dia e notas recentes.

Matriz de Eisenhower & Triagem

Classifique tarefas nos quadrantes Q1–Q4 com arrastar e soltar, rolagem fluida, promoção automática por prazo e modo Triagem Guiada sem distrações.

Pomodoro & Insights

Barra persistente de foco e cronômetro por tarefa, histórico de execução, precisão das estimativas e gráficos de atividade para 1, 7 e 30 dias.

Listas, Subtarefas & Seleção em Lote

Captura em linguagem natural (PT/EN), seleção múltipla estilo Dolphin com Ctrl e Shift, Desfazer/Refazer atômico, recorrência RRULE e exportação para PDF/.ics.

Rotina & Diário AES-256-GCM

Blocos diários e semanais de rotina além de cadernos em Markdown com trava local por senha criptografada em AES-256-GCM antes de qualquer envio.

Nextcloud & Agenda Externa

Sincronização incremental CalDAV (VTODO e VEVENT) + Nextcloud Notes API, com leitura passiva e separada de arquivos .ics / KOrganizer no Resumo.

Arquitetura & Segurança

Local primeiro, criptografado e sem telemetria

SQLite WAL + Backups Locais

Seus dados vivem em ~/.local/share/ktasks/ktasks.db com snapshots automáticos pré-migração. Funciona 100% offline, sem conta obrigatória.

Credenciais no Cofre do Sistema

Tokens Nextcloud (via Login Flow v2) e CalDAV ficam guardados no KWallet / Secret Service via QtKeychain — nunca em texto puro ou logs.

Código Aberto Auditável

Licença GPL-3.0-or-later, zero rastreamento e build contínuo no GitHub Actions com suíte de testes automatizados (C++ / CalDAV / Sync / UI).

Instalação

Baixe o pacote para sua distribuição

Pacotes assinados por checksum SHA-256 gerados automaticamente no GitHub Actions a cada release.

Flatpak Bundle (org.kde.Platform//6.10)

Recomendado para Ubuntu, Fedora, Debian, Mint, openSUSE e desktops não-Arch.

Baixar .flatpak (v1.0.9) 
flatpak remote-add --if-not-exists --user flathub https://dl.flathub.org/repo/flathub.flatpakrepo
flatpak install --user io.github.marleys439.ktasks-x86_64.flatpak
flatpak run io.github.marleys439.ktasks

Arch Linux / CachyOS / EndeavourOS (.pkg.tar.zst)

Instalação nativa via pacman ou compilação local usando o PKGBUILD incluído.

Baixar .pkg.tar.zst (v1.0.9) 
sudo pacman -U ktasks-1.0.9-1-x86_64.pkg.tar.zst

CMake + KDE Frameworks 6

Compilação direta com suporte completo a KDE Plasma e testes unitários.

SHA256SUMS.txt 
git clone https://github.com/MarleyS439/ktasks.git
cd ktasks
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release -DCMAKE_INSTALL_PREFIX="$HOME/.local"
cmake --build build -j"$(nproc)"
QT_QPA_PLATFORM=offscreen ctest --test-dir build --output-on-failure
cmake --install build --strip
